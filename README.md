# Europa Universalis V Mods

This project contains five separate EU5 mods. Each mod is self-contained in its own folder:

- **Potential Cities Map Mode** (`EU5_potential_cities`) adds an Economy map mode that highlights rural settlements and towns with more than 30,000 population, helping identify locations that can be upgraded.
- **Region Stats Map Mode** (`EU5_region_stats`) adds three Geography map modes—Region Population, Region Wealth, and Region Development—which display region-wide totals as heat maps.
- **Near Capacity Map Mode** (`EU5_near_capacity`) adds a Population map mode that colours your locations from light green at 80% population capacity to black at 100%.
- **Roman Borders Map Mode** (`EU5_roman_borders`) adds a Geography map mode that distinguishes locations covered by the Restore Roman Borders casus belli, locations required to form the Roman Empire, and locations shared by both.
- **Show Cultural and Religious Advances** (`EU5_cultural_religious_advances`) adds age-grouped Possible Advances to culture and religion hover tooltips, with native embedded advance tooltips.

These are different, independent mods and can be installed or enabled separately. See the README inside each mod folder for full details.

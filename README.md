# Europa Universalis V Mods

This project contains four separate EU5 mods. Each mod is self-contained in its own folder:

- **Potential Cities Map Mode** (`EU5_potential_cities`) adds an Economy map mode that highlights rural settlements and towns with more than 30,000 population, helping identify locations that may be worth upgrading.
- **Region Stats** (`EU5_region_stats`) adds three Geography map modes—Region Population, Region Wealth, and Region Development—which display region-wide totals as heat maps.
- **Near Capacity** (`EU5_near_capacity`) adds a Population map mode that colours your locations from light green at 80% population capacity to black at 100%, with stripes for locations over capacity.
- **Roman Borders** (`EU5_roman_borders`) adds a Geography map mode that distinguishes locations covered by the Restore Roman Borders casus belli, locations required to form the Roman Empire, and locations shared by both.

These are different, independent mods and can be installed or enabled separately. See the README inside each mod folder for full details.

# Region Stats Map Mode

The idea came from a ''One Region Challenge'' I had with a friend.  

This mod adds three separate map modes, **Region Population**, **Region Wealth**, and **Region Development** to the
**Geography** map-mode category, they show what the name suggests.

## Features
All three map modes:
- Show the cached regional total, world rank, percentage of the corresponding
  world total, and number of land locations in the hover tooltip.
- The heat-map palette of the map modes uses the vanilla tax base palette, with light green being the highest and black being the lowest.
- The colours are based on rankings, not absolute values, and colour change is non-linear, details are available in the in game legend.
- To avoid game stuttering, the statistics are only refreshed in one of the following scenarios: once a year on April 1st, at game start, or at save load.

## Compatibility

- Supported game version: **1.3.x** (Should work fine for other versions as well, but untested.)
- Save-game compatible.
- UI-only: no gameplay data is changed.
- Changes the checksum.

# Near Capacity Map Mode

The in game population map mode only shows locations at full population capacity.

You may however want to urbanise earlier due to decrease in growth when near population capacity. This mod adds the **Near Capacity** map mode under the **Population** category that shows this.

## Features
- Locations in the selected country that use over 80\% of the capacity are coloured.
- The heat-map palette goes from light green at 80\% capacity to black at 100\% capacity.
- The hover tooltip at each location, even if uncoloured, show you the exact percentage of the capacity you have used up.
- Each location's local RGO name is displayed over the map colours.
- Shows blue coloured stripes when an eligible location is already being upgraded to the next rank.

## Compatibility

- Supported game version: **1.3.x** (Should work fine for other versions as well, but untested.)
- Save-game compatible.
- UI-only: no gameplay data is changed.
- Changes the checksum.

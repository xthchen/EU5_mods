# Roman Borders Map Mode

The **Restore Roman Borders** CB is a great CB, but only allows you to take lands within some **Roman Borders**. Where are these borders? The game doesn't tell you. They are also not region based but area based, and is completely different to the Roman Empire formation requirements.

This mod adds **Roman Borders** to the **Geography** map-mode category. It compares the locations covered by the **Restore Roman Borders** CB with the locations required to form the Roman Empire.

I thought of adding other CB's, such as the **Invasion of China** CB, but all the others I believe are full region based, which are easy manageable, correct me if I'm wrong. Maybe it can be updated to a special CB map mode if more area/location based CB are present in game.

## Features
The colour coding shows what is covered by the CB and the formation requirement:
- Purple: included only in the Restore Roman Borders CB
- Gold: required only for forming the Roman Empire
- Purple and gold stripes: included in both
- Uncoloured: included in neither

## Compatibility

- Supported game version: **1.3.x** (Should work fine for other versions as well, but untested.)
- Save-game compatible.
- UI-only: no gameplay data is changed.
- Changes the checksum.

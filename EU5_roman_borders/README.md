# Roman Borders Map Mode

Adds **Roman Borders** to the **Geography** map-mode category in Europa
Universalis V. It compares the locations covered by the **Restore Roman
Borders** casus belli with the locations required to form the Roman Empire.

## Colours

- Purple: included only in the Restore Roman Borders casus belli
- Gold: required only for forming the Roman Empire
- Purple and gold stripes: included in both
- Uncoloured: included in neither

The legend and location tooltips identify what each colour represents in game.

## Installation

Copy the `EU5_roman_borders` folder into your EU5 local-mod directory, or create
an empty local mod in the Paradox Launcher and copy this folder's contents into
that mod's folder. The folder containing `.metadata` is the mod root. Enable
**Roman Borders** in a playset and launch the game.

## Compatibility

- Target: EU5 1.3.*
- Save-game compatible
- UI-only: does not alter borders, casus belli conditions, formation
  requirements, or other gameplay data
- Additive: does not replace the vanilla `map_modes.txt`
- Changes the checksum

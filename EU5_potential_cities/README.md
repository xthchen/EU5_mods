# Potential Cities Map Mode

I found it tedious to urbanise by looking at the ledger and finding settlements with bad RGOs and above 30,000 population, hence this mod.

This is an UI-only mod that adds a new map mode to the **Economy** category. It highlights the rural settlements and towns in the country you are viewing that have more than 30,000 population.

## Features

- Highlights only eligible locations owned by the country you are viewing.
- Uses the vanilla Location Rank colour scheme: rural settlements are red and towns are black.
- Shows coloured stripes when an eligible location is being upgraded to the next rank.
- Displays each location's local RGO name over the map colours.
- Cities, locations at or below 30,000 population, foreign locations, and unowned land are uncoloured.

## Compatibility

- Supported game version: **1.3.x** (Should work fine for other versions as well, but untested.)
- Save-game compatible.
- UI-only: no gameplay data is changed.
- Changes the checksum.
